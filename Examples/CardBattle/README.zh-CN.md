# Card Vanguard / 卡牌对决（uGUI 迷你卡牌小游戏）

基于 Overload 原生渲染管线与托管 **uGUI**（`Graphic` 自绘网格、`Text` 字体渲染、`CanvasScaler` 屏幕自适应、`EventSystem` 输入拾取与交互）打造的单人回合制轻肉鸽卡牌对决小游戏。

---

## 游戏特色

1. **纯正 uGUI 架构与自适应布局**：
   - 使用 `CanvasScaler`（参考分辨率 960×540，`ScaleWithScreenSize`），完美适配宽屏、窗口缩放及各种显示比例。
   - `Graphic` 动态程序化图元生成：包含地牢竞技场地台、玩家骑士徽章、多关卡首领外形与呼吸起伏动画、卡牌阴影/三层边框/法力水晶/卡面图标、血条与护盾徽章。
   - 动态 `Text` 标题与战斗日志（回合播报、飘字伤害数值、卡牌与按键提示）。

2. **核心卡牌玩法（类杀戮尖塔 Slay the Spire）**：
   - **手牌管理**：每回合抽 4 张卡牌（牌库耗尽自动洗牌），每回合提供 3 点法力水晶。
   - **丰富卡组**：
     - ⚔️ **斩击 (Strike)**：耗能 1，造成 7 点物理伤害。
     - 🛡️ **铁壁 (Defend)**：耗能 1，获得 6 点护盾格挡。
     - 🔥 **炎爆术 (Fireball)**：耗能 2，造成 16 点巨额火焰爆发伤害。
     - 🗡️ **连击 (Quick Slash)**：耗能 1，造成 4 点伤害并立即额外抽取 1 张牌。
     - ✨ **圣光 (Holy Light)**：耗能 1，恢复 8 点生命值。
   - **首领关卡推进与意图机制**：
     - **第 1 关**：🟢 **史莱姆王 (King Slime)** - 基础生命 36，掌握轻击与重砸。
     - **第 2 关**：👹 **哥布林督军 (Goblin Warlord)** - 基础生命 52，高护甲与劈砍。
     - **第 3 关**：🐉 **远古赤龙 (Ancient Red Dragon)** - 基础生命 78，狂暴烈焰吐息。
     - **意图指示器**：敌人头顶实时展现下回合行动（攻击 ⚔️、防御 🛡️、重击 💥、治愈 💚），支持针对性博弈。

3. **视觉与交互反馈**：
   - 卡牌鼠标悬停交互：鼠标滑过手牌时，卡牌自动上浮 25px 并泛出高亮金边。
   - 实时飘字系统：造成伤害（红色 `-16`）、护盾获取（蓝色 `+6 🛡️`）、生命治愈（绿色 `+8 💚`）平滑升起渐变消隐。
   - 受击白闪与震动动画。

## 快速启动与游玩

### 方式一：一键脚本启动（推荐）

在仓库根目录下直接双击运行：
```cmd
Launch-CardBattle.bat
```

### 方式二：手动构建并启动

在仓库根目录下运行构建脚本编译 C# 程序集并生成本机项目绑定：
```powershell
node Examples/CardBattle/build.mjs
```

接着启动编辑器打开该项目：
```powershell
& .\Build\Debug\OvEditor.exe (Resolve-Path .\Examples\CardBattle\CardBattle.local.ovproject).Path
```

在编辑器中打开 `Assets/Scenes/CardBattle.ovscene`，点击上方 **Play** 按钮即可在 **Game View** 畅玩！

## 游戏操作指南

| 操作 | 对应快捷键 | 效果 |
|---|---|---|
| **打出卡牌** | 鼠标左键点击卡牌 / 键盘数字键 `[1]` ~ `[6]` | 消耗能量打出对应手牌并触发攻击/防御/治疗效果 |
| **结束回合** | 鼠标点击右下角 `END TURN` 按钮 / 键盘 `[SPACE]` 或 `[E]` | 结算本回合，切换至敌方执行意图行动，随后重新抽牌并恢复能量 |
| **重新开始** | 键盘 `[R]` 键 / 结算弹窗点击 | 随时重新初始化对局（或在战败/通关后重开新挑战） |
| **下一关卡** | 胜利弹窗点击 / 键盘 `[SPACE]` 键 | 击败首领后回血并进阶至下一关卡敌人 |
